# HR Analytics Cloud Data Project

A comprehensive HR analytics solution for analyzing employee data, predicting attrition, performance evaluation, and generating actionable insights.

## Project Structure

```
hr-analytics/
├── README.md
├── requirements.txt
├── .gitignore
├── main.py
├── data/

│   │   └── hr_data.csv
│   └── processed/
├── src/
│   ├── __init__.py
│   ├── config.py
│   ├── preprocessing.py
│   ├── eda.py
│   ├── features.py
│   ├── attrition_model.py
│   ├── performance_model.py

│   └── reports/
├── dashboard/
│   └── HR_Analytics.pbix
└── docs/
    ├── final_report.pdf
    └── presentation.pptx
```

## Features

- **Data Preprocessing**: Clean and prepare HR data
- **EDA Analysis**: Exploratory data analysis with visualizations
- **Feature Engineering**: Create meaningful features for modeling
- **Attrition Prediction**: Machine learning model for employee attrition
- **Performance Analysis**: Evaluate employee performance
- **Clustering**: Segment employees into personas
- **Insights Generation**: Automated insights and recommendations

## Installation

```bash
pip install -r requirements.txt
```

## Usage
